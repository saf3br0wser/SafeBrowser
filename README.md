## What is SafeBrowser?

SafeBrowser is a browser companion powered by **Apple Shortcuts** and lightweight web interfaces. Its goal is simple: make finding and opening websites feel fast, intuitive, and effortless — without the complexity of a traditional app.

SafeBrowser combines shortcut automation with a consistent, minimal interface designed around **fewer taps and smoother navigation**.

## Features

- **Fast opening** — Quickly access websites through shortcut-driven flows.
- **Square Opener** — Launch saved websites from a simple visual interface.
- **Discover** — Explore websites and find something new.
- **Profiles** — Keep browsing preferences organized with separate profiles.
- **Flexible storage** — Choose between local storage and iCloud for profile data.
- **Lightweight design** — Clean, consistent interfaces built to stay out of your way.
- **Apple Shortcuts integration** — Connect web interfaces and native iOS actions.

> SafeBrowser is an evolving project. Some features may differ by version or still be in development.

## Getting started

1. Visit the [SafeBrowser website](https://safebrowser.website/) or check [Releases](https://github.com/saf3br0wser/SafeBrowser/releases) for available installation information.
2. Add the SafeBrowser shortcut using the instructions provided with the release.
3. Run the shortcut and follow the onboarding steps to set up your profile and storage preference.

## Built around simplicity

SafeBrowser follows three guiding ideas:

- **Fewer taps:** Avoid unnecessary menus and transitions.
- **One experience:** Keep shortcut actions and web pages feeling connected.
- **Your choice:** Offer straightforward ways to organize and store your data.
